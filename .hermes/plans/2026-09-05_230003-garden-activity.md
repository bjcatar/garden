# Garden v2 — Observed coding activity

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Turn Garden into a private Omarchy calendar of *observed coding activity in folders the user chose on this machine* — not GitHub.com, not token quotas, not “commits that happen to exist in a clone.”

**Architecture:** A local ledger sampler (systemd user timer, one process) writes append-only `ledger.jsonl` plus a derived `heatmap.json`. The QML widget only *reads* JSON (no per-monitor scan). Each day square is the count of **active 30-minute slots** (0–48). A slot lights if any qualifying signal fired in that half-hour in a watched root. Day panel lists sources; the square stays one accent color.

**Tech stack:** Python 3 stdlib scanner, Omarchy bar-widget QML (`qs.Commons` / `qs.Ui`), `~/.local/state/omarchy/garden/`, widget settings in `shell.json` + `settings.json`.

**Reviewers (2026-09-05):** GPT-6 Astra and Claude Fable 5.1 independently reviewed the current plugin. They **agreed** on the product, one-color UI, user-picked roots, no Agents clone, no transcript parsing, and rejecting a weighted “blend score.” They **disagreed** on git’s confidence (Astra: history ≠ this machine; Fable: authored commits may light a slot). Consensus below takes Astra’s honesty about git *and* Fable’s slot union so uncommitted typing still counts.

## Product (locked)

**One-liner:** Garden is a private calendar of observed coding activity in folders you choose on this machine.

**Unit:** Active half-hours today / this year. Tooltip: `6 active hours · 3 commits · files in 2 repos`. Never “productivity score.”

**Signals (v1):**

| Signal | Lights a 30-min slot when | Notes |
|---|---|---|
| File edit | A *tracked* file under a watched root has mtime in that slot (`git ls-files` + `stat` only) | Covers human typing and agent edits. No contents. Untracked ignored (drops build junk). Unchanged dirty tree does not keep scoring. |
| Git commit | Author **email** matches configured identity; commit date local; subject not in ignore regex | Floor of 1 slot, not a multiplier. Default ignore: `^vault backup:`. Mute individual repos. |
| Agent (optional, off by default) | `agents/usage/*.json` `recentDays.messageCount` increased since last sample | No directory attribution. Do **not** use tokens. Do not parse transcripts. |

**Not v1:** Herdr cwd, Hermes/Claude/Codex transcript mining, keystroke/focus watchers, additions/deletions as score, split/layered cells, GitHub API, Hermes UI.

**Unknown vs empty:** Days before the ledger started are *unknown* (distinct empty color or hatch), not “you did nothing.” Git-only history may show as a labeled pale floor (“git history only”) — Astra’s requirement.

**Roots:** Suggest `~/Projects` if it exists. **Do not default to `~/Documents`.** Reject `$HOME`. Canonicalize, preserve case, dedupe overlaps. Empty watch list = watch nothing (do not silently restore defaults).

## Current bugs to fix while rebuilding

From Astra + Fable (current `bin/garden-scan`, QML):

- Missing git identity silently counts everyone; name-or-email matching is too loose → **email only**.
- `git log --all` counts fetched remote history → prefer current branch + optionally `--author` on local commits; never other people’s clones.
- 4 years of `--numstat` for a 365-day grid; repo totals mix year ranges.
- Two monitors × `triggeredOnStart` Timer = scan storm → **systemd timer only**.
- Atomic `tmp.replace` may break FileView inode watch → write in place or verify.
- Inclusive 366-day range can yield **54** week columns.
- “Today” uses cached `snapshot.today` across midnight.
- Hermes leftover (`dashboard/`, `desktop/`, `plugin.yaml`) rsynced into the plugin dir.

## Task 2: Settings schema

**Objective:** Roots, ignores, and source toggles live in one file.

**Create:** `~/.local/state/omarchy/garden/settings.json` (written by panel; read by scanner)

```json
{
  "roots": ["~/Projects"],
  "excludeRepos": [],
  "ignoreSubject": "^vault backup:",
  "authorEmails": [],
  "sources": { "files": true, "git": true, "agents": false },
  "slotMinutes": 30
}
```

Empty `roots` means watch nothing. Empty `authorEmails` means read `git config --global user.email` only; if missing, git signal is off (do not count everyone).

**Test:** `tests/test_settings.py` — empty roots do not fall back to Documents; `$HOME` rejected by a `validate_root()` helper.

## Task 6: Single scanner process + heatmap.json

**Objective:** One writer.

- `bin/garden-scan` appends to `ledger.jsonl`, rebuilds `heatmap.json`
- File lock (`fcntl`) so two timers cannot overlap
- systemd user unit: `garden-scan.timer` every 15 min (`OnUnitActiveSec=15min`)
- Widget **must not** start `Process { python3 garden-scan }` on a Timer

`heatmap.json` days:

```json
{
  "date": "2026-09-05",
  "slots": 6,
  "commits": 2,
  "files": 12,
  "repos": ["local-contrib"],
  "coverage": "observed"
}
```

`coverage`: `observed` | `git-history-only` | `unknown`

Verify FileView still updates (write in place or rewrite via same inode).
